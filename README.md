# 15歳のAI・ガジェット研究所（ai-gadget-lab）

15歳（中学3年生）が、実際に使ったAIとガジェットの記録を、点数とデータで残すWebサイトです。

## このサイトで見られるもの
- AI批評データ：31のAIを5つの基準で採点（TOP10を掲載）
- 実機データベース：持っている機種だけの満足度と実測記録
- スマホ批評データ：7万円以下のコスパ批評と、10万円以上のフラッグシップ批評
- 開発記録：このサイト自体をどう作ったかの記録（失敗も含む）

## 作り方（役割分担の実験）
- Muse：企画・要件定義・コード作成（PM＋AI開発者）
- GitHub：コード管理と公開（このリポジトリ、GitHub Pages）
- Juno：Pythonによるデータ処理とグラフ作成（juno/ フォルダ）
- リョウ（本人）：データ提供、Junoの実行、最終確認、公開判断

## データについて
点数と数字は、note「15歳視点 | AI・ガジェット研究室」の記事で公開した検証済みのものを使っています。価格は確認日を併記し、裏取りしていない数字は掲載しません。持っていない機種は実体験として書かず、「15歳の条件で買うか」の判断として扱います。

note: https://note.com/pure_donkey1452
