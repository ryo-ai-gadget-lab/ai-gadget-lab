# Juno実験 — 実施済み（2026-11-22）

Junoはアカウント不要のiOS / iPad用Python・Jupyterアプリです。リョウがiPhoneで、無料の範囲で実行します。このフォルダのコードはJunoでも `python3` でも同じように実行できます（matplotlibが必要です）。

## 実験一覧（3件に固定）

### 実験1：note運営データのグラフ化 — 完了
- 入力：`juno/note_data.csv`（検証済み合計のみ。出典：noteアクセス状況、2026-11-22 15:50集計）
- 処理：`juno/exp1_note_data.py`
- 出力：`data/chart-note-periods.png`（2期間の合計比較）、`data/chart-note-inflow.png`（流入元円グラフ）
- 注意：日別バーの高さは数値として読めないため、日別推移グラフは作っていない。合計値のみ。2026-09-28〜10-25のコメント数はスクリーンショットに表示がなく、0とは限らないため空欄。

### 実験2：AI批評の採点データの集計・棒グラフ化 — 完了
- 入力：`data/ai_top10.json`（TOP10の合計点 + 特別枠 Claude Ultra 67点）
- 処理：`juno/exp2_ai_scores.py`
- 出力：`data/chart-ai-top10.png`
- 注意：サイトに載せるのはTOP10です。グラフもTOP10を基本とし、Claude Ultraは18歳以上限定の特別枠として別色で一番下に描いています。31AIすべての5基準内訳は元データにないため、合計点のみ。

### 実験3：実機の価格と満足度の散布図化 — 完了
- 入力：`data/devices.json` + 検証済み価格（iPhone 11：38,000円、POCO F7 Pro：約60,000円）
- 処理：`juno/exp3_devices.py`
- 出力：`data/chart-devices.png`
- 注意：Xiaomi PadとゲーミングPCは未採点のため、散布図には含めません。Galaxy A25 5G（60点）は価格が未確認のため、価格を推測で入れず除外しています。価格が2点しかないため傾向線・相関の主張はしません。価格は当日に公式・販売サイトで裏取りした数字だけを使います。

## 手順（共通）

1. JunoをApp StoreからiPhoneにインストールする
2. このフォルダのPythonコードを実行する
3. できた画像を `data/` に入れる
4. サイト側は画像ファイル名だけを参照する（数字の修正はサイト側ではしない）

## 問題が起きたときの切り分け
