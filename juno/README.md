# Juno実験 — プレースホルダー（Phase 1）

Junoはアカウント不要のiOS / iPad用Python・Jupyterアプリです。リョウがiPhoneで、無料の範囲で実行します。グラフはまだ作られていません。**ここにグラフ画像を勝手に作らないでください。**

## 実験一覧（3件に固定）

### 実験1：note運営データのグラフ化
- 入力：note運営データのCSV（表示・PV・流入元）
- 処理：PythonでPV推移と流入元の割合を集計
- 出力：`data/chart-note-pv.png`、`data/chart-note-source.png`
- 状態：未実施

### 実験2：AI批評の採点データの集計・棒グラフ化
- 入力：AI批評の採点データ（31AI × 5基準）のCSV
- 処理：Pythonで集計し、棒グラフ化
- 出力：`data/chart-ai.png`
- 状態：未実施
- 注意：サイトに載せるのはTOP10です。グラフもTOP10を基本とします。

### 実験3：実機の価格と満足度の散布図化
- 入力：実機の価格と満足度のCSV
- 処理：Pythonで価格 vs 満足度の散布図化
- 出力：`data/chart-price.png`
- 状態：未実施
- 注意：Xiaomi PadとゲーミングPCは未採点のため、散布図には含めません。価格は当日に公式・販売サイトで裏取りした数字だけを使います。

## 手順（共通）

1. JunoをApp StoreからiPhoneにインストールする
2. このフォルダのPythonコードを実行する
3. できた画像を `data/` に入れる
4. サイト側は画像ファイル名だけを参照する（数字の修正はサイト側ではしない）
